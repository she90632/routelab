範例作品

這頁怎麼玩

  1. 點下面的快速按鈕問常見問題，或自己打字，例如「週一有開嗎」「有素食嗎」。
  2. 直接打訂單：「11/8 肉桂捲 2 個、可頌三個 下午3點拿」，會自動拆成品項、數量、取貨日時間，寫進右邊（手機版在「訂單表」分頁）。
  3. 客人回「確認」，狀態就從「待確認」變「已確認」；在表上點狀態可以改成「已取貨」或「已取消」。
  4. 右上角可以切換不同客人，看多筆訂單怎麼依日期、狀態、品項排好。

正式版會怎麼接

正式上線時，對話這一側換成 LINE Messaging API：店家的官方帳號設定 webhook，客人傳訊息時由伺服器套用同一套關鍵字規則回覆，答不出來就轉給真人。訂單那一側用 Google Sheets API 寫進店家自己的試算表。這個示範沒有連任何帳號、沒有金鑰，所有對話和訂單只存在這個瀏覽器的 localStorage，清掉就沒了。
